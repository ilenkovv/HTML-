# Web Master / HTML-

Резервный GitHub-контур проекта «Веб Мастер».

Цель продукта: простой мастер публикации веб-приложений для нетехнического пользователя.

Основной пользовательский поток:

`Файл → Пользователь → Загрузка → Проверка кода → Настройка приложения → Размещение → Готово`

В этот репозиторий переносится проверенный код, который больше не должен зависеть только от Lovable.

## Уже разработанные направления

- безопасная загрузка и публикация HTML/ZIP;
- версии, rollback и hardening ZIP;
- безопасные публичные URL и SPA/404 routing;
- PostgreSQL/Supabase + Storage;
- модуль «База ИИ»: события, feedback, dataset versions, JSONL/CSV export;
- следующий блок: поля БД/ИИ, связи сущностей, многопользовательский режим, роли, административная панель и дашборд;
- REG.RU/VPS deployment agent — отдельный этап, без хранения пароля личного кабинета.

## Важно

Текущий Lovable-проект остаётся отдельным upstream до полной синхронизации исходников. Не смешивать старую Express-версию с текущим TanStack/Supabase приложением.
